Healthcare 360 – Patient Health Analytics

Project Overview

Healthcare 360 is a healthcare data analytics project developed using Tableau Public. It explores patient demographics, health conditions, and lifestyle factors through interactive visualizations.

Tools Used

- Tableau Public
- CSV Dataset
- Data Visualization

Key Visualizations

- Age Distribution
- Heart Disease by Gender
- Diabetes by Gender
- Smoking Distribution
- Exercise Level Distribution
- Heart Disease by Age Group
- Cholesterol Analysis by Gender
- Glucose Analysis by Gender

Live Dashboard

"View Interactive Healthcare 360 Dashboard" (PASTE_YOUR_TABLEAU_PUBLIC_LINK_HERE)

Project Objective

To explore healthcare data and identify patterns in patient demographics, health conditions, and lifestyle-related variables using data visualization.

Conclusion

This project demonstrates the use of Tableau Public to transform healthcare data into interactive and understandable visual insights.
